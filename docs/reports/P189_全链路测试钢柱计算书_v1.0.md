## 6. 独立手算对照（`docs/07 §13.5` 的 H400×400×13×21，仅供量级参考）

> ⚠️ 本节是**另算**，与 §4 真机数值**不是同一截面**，仅作 H400 尺寸柱的力学量级参照，**不用于替换 §4 结论**。

截面特性（H400×400×13×21）：

| 量 | 值 |
| --- | --- |
| A | 21454 mm²（214.54 cm²） |
| Ix | 6.536×10⁸ mm⁴（65362 cm⁴） |
| Iy | 2.241×10⁸ mm⁴（22407 cm⁴） |

| Wy | 1.120×10⁶ mm³（1120 cm³） |
| ix / iy | 174.5 mm / 102.2 mm |

轴压校核（E=206000 N/mm²，计算长度 6 m、铰接）：

| 量 | 值 |
| --- | --- |
| 屈服轴力 Ny = A·fy(355) | 7616 kN |
| 弹性屈曲 Pcr,x（绕强轴） | 36914 kN |
| 弹性屈曲 Pcr,y（绕弱轴） | 12654 kN |

对照：施加轴压 500 kN，对真实 H400×400×13×21 而言 `500 / 7616 ≈ 6.6%` 的屈服轴力 —— **量级上远不超限**。而 §4 真机在占位截面 `P154S1` 上得 `ratio = 1.814（NG）`，说明**占位截面 `P154S1` 的截面承载远小于真实 H400** —— 这正印证 §5：两者不是同一截面，不可混用。
