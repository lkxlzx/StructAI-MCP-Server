# P188 —— `DESIGN.RC.REBR` 的 `400` 真机归因（REBC 同族）

> 批次：**P188**（真机写实验，延续 P186-B 的授权；`gen-local` 空项目）
> 目的：验证 `REBR`（REBC 同族）的 `400` 是否**与前置对象无关**、归因 = 键名/形状层；
> 若同族同因 ⇒ **REBC/REBR 合并为同一问**，避免问题膨胀。
> 红线：阳性对照先行（R157）· 判据 = 效果 + 原生文案（铁律 ⓪）· 零残留 · 不碰 `*-ANAL`（R154）。
> 证据：`registry/live/rebr_prereq_probe_p188.json`。

---

## 1. 结论（一句话）

`REBR` 与 `REBC` **完全同族同因**：在**前置单元真实存在**时，`PUT /DESIGN/RC/KDS-41-20-2022/REBR`
仍回 **`400 {"error":{"message":"Wrong Field"}}`**（与 REBC **逐字相同**）、`GET` 读回 `{}`。
⇒ 归因同为**请求体形状/键名层**，**与前置对象无关**；**REBC/REBR 合并为一问**（向 MIDAS 问法里端点写「REBC 或 REBR」即可）。

## 2. 实测事实（原生文案为准）

| # | 步骤 | 方法 | 原生结果 |
|---|---|---|---|
| 0 | 基线：空项目 | `GET /db/NODE` `/db/ELEM` | `200 {"message":""}`（空） |
| 1 | **阳性对照**：建节点 1/2 → 读回 | `POST /db/NODE` ×2 | **`201`** + 读回真值 |
| 2 | 前置：建单元 1（节点 1→2） | `POST /db/ELEM` | **`201`** + 读回 `NODE:[1,2,0,…]` |
| 3 | **目标：`PUT REBR`（单元 1 已存在）** | `PUT /DESIGN/RC/KDS-41-20-2022/REBR` | **`400 {"error":{"message":"Wrong Field"}}`** |
| 4 | 读回 | `GET /DESIGN/RC/KDS-41-20-2022/REBR` | `200 {"REBR":{}}`（未落库） |
| 5 | 清理（逆序删单元→节点2→节点1） | `DELETE` ×3 | `200` |
| 6 | **零残留核对** | `GET /db/NODE` `/db/ELEM` | `200 {"message":""}` ⇒ 空 ✅ |

## 3. 与 P186-B（REBC）的对照

| 维度 | REBC（P186-B） | REBR（P188） |
|---|---|---|
| 结构 | `Assign → 截面号 → ITEMS[]`（required `MAIN_BAR/SHEAR_BAR_END/SHEAR_BAR_CEN/DO`） | **同构** |
| 前置无关 | 有单元仍 `Wrong Field` | **同**（逐字相同文案） |
| 读回 | `{}`（未落库） | **`{}`** |
| 归因 | 键名/形状层（`Wrong Field`，同 P169 `TABLE_TYPE`→`TEXT_TYPE`） | **同** |
| 结论 | — | **合并为一问** |

## 4. 为什么不再单独提第 6 问

`REBC` 与 `REBR` 的 `Assign/ITEMS` 结构、`400` 文案、前置无关性**逐项一致** ⇒ 它们极大概率是
**同一处请求体契约**在「柱配筋 / 撑配筋」两种端点上的复用。向 MIDAS 提**一问**（端点写「REBC 或 REBR」）
即可覆盖两者，且符合「不制造重复问题」的交付纪律。

## 5. 附带确认（正面结果）

- **仪器有效**：`POST /db/NODE` / `/db/ELEM` 均 `201` + 读回真值；`DELETE` 后回空 ⇒ 阳性对照成立（R157）。
- **零残留**：实验后 `GET /db/NODE` / `/db/ELEM` 均 `{"message":""}`。
- **未碰崩溃族**：`REBR requires_analysis=false`，全程未发任何 `*-ANAL`（R154）。
