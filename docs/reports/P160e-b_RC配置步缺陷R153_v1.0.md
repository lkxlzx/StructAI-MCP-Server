1. **"已获授权"不等于"现在就该动"**：授权是**许可**，不是**义务**。上下文将尽时动 `app/**`，
   风险是留下**半成品**（R143 / R148 都证明"接一半必炸"）⇒ **登记 + 交接**比硬做更负责。

   RC **没有** ⇒ 多出一块（4 个新转换器）⇒ 工时与风险都不同。
