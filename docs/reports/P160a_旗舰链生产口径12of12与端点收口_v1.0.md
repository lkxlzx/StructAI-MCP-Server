## 8. 本批的教训

1. **"我们证明了它能跑" ≠ "产品能跑"** —— 只要探针**默认**开旁路，链的 `PASSED` 就**不能**读作
   生产可用。⇒ 探针的**默认口径必须等于生产口径**；旁路要**显式**开。
2. **先算"完成度"再动手**：把"71 个 Operation 的生产可用性"算出来，才知道该先修哪 3 个端点 ——
   比按台账顺序做剩余项**收益高一个量级**（+8 个 Operation / 3 个端点）。
3. **收口的依据要能指回证据**：3 个端点的 `verified_on` 都指向同一份真机证据
   （`registry/live/flagship_chain_probe.json`），**不**靠"应该能用"。
