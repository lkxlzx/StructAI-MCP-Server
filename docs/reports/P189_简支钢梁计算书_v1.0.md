## 5. ⚠️ 截面声明（诚实性说明，务必阅读）

链路与数值 **100% 来自真机**（分析 + 设计均 MIDAS 真实返回）。截面 `P154S1` 是 `DBUSER` + `SB` + `vSIZE=[1,1]` 的**占位截面**（P154 遗留，未给真实 H 型钢尺寸）。

因此 §4 承载力对应**占位截面**，**不是**真实 H 型钢。
**定位**：本计算书是**全链路功能性 + 力学正确性**验证 —— 关键是 §6 的**手算对照**证明分析结果物理正确；它**不冒充**真实截面梁的正式设计计算书（那需换真实 H 型钢 DBUSER 尺寸，守 R151 不臆造）。

## 7. 结论

1. **简支梁全链路真机跑通**：SAVE_AS → 建模 → 荷载 → 组合 → 分析 → 结果 → 设计，**16 / 16 PASSED**，零残留，**保存带路径（R143，无弹窗）**，**材质/设计规范同区域（GB 中国体系，三处同族）**。
2. **分析结果物理正确**：跨中弯矩 440000、支座剪力 −110000，与手算 PL/4=400000 / P/2=100000 高度吻合。
3. **设计验算 = NG**：`GB50017-03` 下弯矩需求（440000）远大于占位截面 `P154S1` 承载力（47254.7，约 9.3 倍）⇒ 占位截面过小。
4. **截面诚实声明**：验算用占位截面 `P154S1`（非真实 H 型钢）；计算书定位为全链路功能性 + 力学正确性验证。
5. **下一步（真实截面正式计算书）**：把 `P154S1` 换成真实 H 型钢 DBUSER 尺寸（守 R151），重跑即得真实截面梁的 GB50017 正式验算。

## 8. 关键教训（本批踩坑记录）

- **R143 铁律**：DESIGN 前**必先 `SAVE_AS` 带项目路径**，否则 MIDAS 弹「另存为」模态框阻塞 API（本轮已按此根治，无弹窗）。
- **同区域铁律（R169）**：设计规范三处必须同族 —— `DSTL.DGNCODE` · `MATL.STANDARD` · 材质码。**中国材质（Q355/GB50017）+ 韩国规范（KDS）⇒ 引擎找不到组合 ⇒ `400 failed:LoadCombination`**。本批改**中国体系**（`GB50017-03` + `GB50017-17(S)` + Q355）后 DESIGN 通过。
- **R135**：STATIC 分析是触发式的，`RESULT` 前需**有界等待**（本探针分析后等 20s + 重试窗口），否则 `[empty] no analysis result`。
- **截面**：`MODEL.SECTION.ASSIGN` 必带 `SECT_I.vSIZE`（缺 ⇒ `截面尺寸输入有错误`）。
